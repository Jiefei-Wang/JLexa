# Pixel 6 UI and functional validation — 2026-09-06

Device: Pixel 6, serial `25311FDF6004PR`, Android 16. Tested existing application data with Qwen2.5 0.5B and Whisper Tiny in the persisted Android SAF model folder. Release upgrades preserved existing lessons and downloaded models. Dart iterations used Flutter hot reload; release validation used the signed APK.

## Findings and changes

| Finding | Change |
| --- | --- |
| The traditional dictionary contained only 31 curated entries; ordinary words were missing. | Added a separately versioned, read-only ECDICT learner database with 57,961 entries and MIT attribution. Existing curated entries retain precedence. The reproducible builder and source digest are included. |
| Prefix lookup could display a different word as an exact result. | Exact lookup now stays exact; prefix matches appear only in suggestions. Literal wildcard searches and cleared history are covered. |
| Sentence queries lost punctuation/case, overflowed narrow screens, and could not save AI-only translations. | Preserve the submitted sentence, wrap long headers, constrain suggestions above the keyboard, and enable vocabulary saving for AI answers. Draft typing and asynchronous saves cannot retarget the current result. |
| Small-model dictionary generation copied JSON placeholders, echoed English, or repeated definitions. | Removed placeholder-heavy prompts, use direct Chinese translation instructions and traditional Chinese definitions as word context; added native repetition penalties and removed duplicate token acceptance. Generated content remains explicitly labeled as AI. |
| Playback after EOF displayed a playing state without replaying the source. | Keep the native source with `ReleaseMode.stop`, preserve the final position, and seek to zero when replaying. |
| A loop seek completing after Pause could resume playback. | Guard loop resumption with a playback generation; regression test pauses inside the pending loop seek. |
| Long sentence cards and review buttons overflowed or overlapped Android system navigation. | Wrap/scroll long text and add safe areas to review, chat, settings, and word explanation sheets. |
| Explanation failures removed the retry action; generation lacked cancellation. | Always retain regeneration, display streaming text, and allow cancellation with stale-result invalidation. |
| Recent Lookups “See all” and chat History were inert. | Added usable history sheets; chat history is accurately scoped to the current conversation. The Home translation shortcut opens a blank AI query. |

## Device coverage

- Dictionary: ordinary offline lookup, prefix suggestions, missing entries, long sentence input with keyboard, tab switching, AI generation/cancellation, Chinese sentence translation on CPU and Vulkan, vocabulary saving, and revisiting search results.
- Repeater: WAV and MP3 lessons, a fresh WAV import, automatic pause-based cuts, previous/next navigation, seeking, per-cut repeat, pause, replay after EOF, manual and Auto Whisper transcription, cut changes/cancellation, restored transcript display, word popup/save, and manual sentence explanation.
- Fresh WAV produced `Hello` and `This is a real speech recognition test` on separate speech regions; the latter showed 96% model confidence. MP3 returned `I am learning English with` on the selected region. Confidence is model output, not a measured accuracy score.
- Repeat-one ran about 40 observed cycles over the selected `5989–7471 ms` cut. Replaying a completed ten-second lesson advanced from the beginning again.
- Study: saved word and sentence cards, reveal answer, grade answers, and complete a two-item review. The bottom controls remained above Android's navigation bar.
- Home and Ask AI: all main tabs, recent-search sheet, example prompts, current-conversation sheet, microphone permission and start/stop with no supplied speech. Microphone speech accuracy was not benchmarked.
- Settings/model runtime: existing SAF paths and models survived restart/upgrade; CPU and Vulkan generation were exercised. This pass did not delete/redownload the existing model files or exhaustively test every model/provider combination.

## Remaining product limitations

- Qwen2.5 0.5B can still give inaccurate, incomplete, or repetitive explanations. The final sample stopped its previous runaway repetition but still mislabeled word senses; a sentence explanation also mistranslated speech recognition. Prompt/sampling improvements are not an accuracy guarantee; traditional dictionary results should remain available for comparison.
- Automatic segmentation uses acoustic pauses, so a grammatical sentence can span multiple cuts. Proper names and very short/noisy cuts remain difficult for Whisper Tiny. Manual cut adjustment and retranscription remain necessary controls.
- The bundled database is a learner subset, not the full ECDICT. It does not manufacture examples or synonyms where the source has none.
- Chat History currently covers the active conversation, not persistent conversations across process restarts.
- This is a focused physical-device regression pass across the app's principal flows, not an exhaustive test of every Android device, font scale, long recording, storage provider, or failure condition.
- Automatic approval review rejected removal of duplicate build-output APKs with `blocked by policy`. The fixed release artifact is current, but the debug/release copies under `app/build/app/outputs/` remain.
